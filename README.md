# Netflix Content Analysis using Python

## Project Overview

This project explores and analyzes a Netflix Movies and TV Shows dataset using Python. The objective is to perform Exploratory Data Analysis (EDA), identify content trends, examine data quality, and extract meaningful insights from the dataset.

The analysis was performed using Python and popular data analytics libraries including Pandas, NumPy, Matplotlib, and Seaborn.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Project Objectives

* Assess data quality and identify duplicate records
* Analyze missing values using visualizations
* Explore content distribution between Movies and TV Shows
* Study release year trends
* Identify top contributing directors
* Analyze content ratings and classifications
* Explore country-wise content distribution
* Perform genre-based filtering and segmentation
* Examine content duration patterns

---

## Key Analysis Performed

### Data Cleaning

* Checked for duplicate records
* Removed duplicate entries
* Identified and visualized missing values

### Content Analysis

* Compared Movies and TV Shows available on Netflix
* Analyzed content released in specific years
* Investigated content produced in different countries
* Explored content based on ratings and genres

### Director and Country Analysis

* Identified the most prolific directors
* Determined countries with the highest content contribution

### Rating Analysis

* Examined Netflix rating categories
* Filtered content based on rating criteria and release periods

### Duration Analysis

* Identified the longest Movies and TV Shows available on Netflix

---

## Key Insights

* Movies constitute the majority of Netflix content.
* Content availability has increased significantly over recent years.
* A small number of directors contribute a substantial portion of titles.
* Content distribution varies considerably across countries and rating categories.
* Netflix offers a diverse catalog spanning multiple genres and audience segments.
